# Basics of HTTP and HTTPS

## Difference between HTTP and HTTPS

HTTP (HyperText Transfer Protocol) is the protocol used for communication between web browsers and web servers. It allows clients to request resources like web pages, images, and API data.

HTTPS (HyperText Transfer Protocol Secure) is the secure version of HTTP. It uses SSL/TLS encryption to protect the data being transferred between the client and the server.

Main differences:

- **Encryption**
  - HTTP sends data in plain text.
  - HTTPS encrypts the data using SSL/TLS.

- **Security**
  - HTTP is vulnerable to interception and attacks.
  - HTTPS protects against eavesdropping and data tampering.

- **Ports**
  - HTTP uses port **80**
  - HTTPS uses port **443**

- **Usage**
  - HTTP is used for general websites.
  - HTTPS is used for secure websites such as banking, login pages, and APIs.
