# JavaScript Warm Up

Introductory JavaScript scripting project for Holberton School.

## Description

A set of scripts covering the fundamentals of JavaScript: variables and
constants, data types, conditionals, loops, functions, scope, and
importing modules. All scripts run with Node.js 14.

## Requirements

- Scripts run on Ubuntu 20.04 LTS with Node.js 14.x
- Every file begins with a node shebang and is executable
- Code is semistandard compliant (16.x.x)

## Usage

Run any script directly from the command line, for example:
./0-javascript_is_amazing.js
