# Python - Everything is Object

An exploration of how Python handles objects, references, and the
distinction between mutable and immutable types.

## Description

This project answers questions about object identity, aliasing, and how
Python passes variables to functions. Answers live in .txt files, one
line each.

## Topics

- Objects, classes, and instances
- References, assignment, and aliasing
- Mutable and immutable built-in types
- Identity comparison with `is` and `id()`
- How Python passes arguments to functions
